# ROLLER

> ROLLER is a cloud-based venue management platform for the attractions and leisure industry (trampoline parks, family entertainment centers, museums, zoos, aquariums, water parks and amusement venues). It unifies ticketing and online bookings, point of sale, memberships, digital waivers, integrated payments, CRM and self-serve kiosks. ROLLER exposes a real-time REST API and a Reporting (Data) API, plus webhooks and OCTO API compatibility. Authentication is OAuth2 client credentials; API access is an add-on to a ROLLER subscription.

## APIs

- [ROLLER REST API](https://docs.roller.app/docs/api/rest): Real-time API for products, sessions, availability and creating/managing bookings. Base URL https://api.roller.app.
- [ROLLER Reporting API](https://docs.roller.app/docs/api/reporting): Read-only Data API for extracting venue data to external databases and BI/analytics platforms.

## Authentication

- [Authentication](https://docs.roller.app/docs/api/authentication): OAuth2 client-credentials flow; exchange client id/secret at https://api.roller.app/token for a short-lived Bearer token. Reuse the token until a 401. Limit: 1 request/second per credential set (429 on exceed).
